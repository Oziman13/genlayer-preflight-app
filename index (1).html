🛫 Preflight

Rule-based on-chain review board — GenLayer Intelligent Contract

What this does

A program owner defines a rubric of weighted rules. Anyone submits a public URL. Independent GenLayer validators each fetch the page and judge every rule on their own, and the contract only accepts a verdict when they agree on every rule that can change the score. The result, and the exact rubric version it was judged against, are stored on-chain.

Known limitations

Runs on GenLayer Studionet, a hosted development network that can be reset. A review takes a minute or more because the page is fetched and judged by several validators. Only public pages can be reviewed. Verdicts are LLM judgments against the rubric, not proof the work is correct.
